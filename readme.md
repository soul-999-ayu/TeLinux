# ⚡ TeLinux v2 - Hybrid Remote Control

**TeLinux v2** is an advanced Python-based automation tool that transforms your Telegram chat into a dual-mode Linux controller. It combines a standard **Chat Shell** for quick commands with a fully interactive **Web Terminal** for advanced tasks.

---

## 🌟 New in Version 2

* **💻 Hybrid Web Terminal:** Run interactive apps like `cmatrix`, `htop`, `vim`, and `adb shell` directly inside Telegram via a secure Web App.
* **🌐 Cloudflare Tunneling:** Secure, encrypted, and unlimited access to your terminal over the internet (No port forwarding required).
* **🛡️ Smart Detection:** The bot automatically detects interactive commands and offers to launch the Web Terminal instead of freezing the chat.

---

## 🛠️ Requirements

* **OS:** Fedora, Ubuntu, Debian, Arch, etc.
* **Python:** 3.12+
* **Core Tools:** `python3-pip`, `ttyd`, `cloudflared`
* **Telegram:** Bot Token from @BotFather.

---

## ⚙️ Installation & Setup

### 1. Install Dependencies
**Fedora:**
```bash
sudo dnf install python3-pip ttyd cloudflared
```
*(If cloudflared is missing, add the repo: `sudo dnf config-manager --add-repo https://pkg.cloudflare.com/cloudflared-ascii.repo`)*

**Ubuntu/Debian:**
```bash
sudo apt install python3-pip ttyd
# Download cloudflared .deb from Cloudflare website
```

### 2. Install Python Libraries
```bash
pip install python-telegram-bot psutil
```

### 3. Start the Backend (Terminal + Tunnel)
You must run this command in the background to enable the Web Terminal feature. 
**Note:** It is recommended to run this from your Home directory.

```bash
# 1. Start Web Terminal on port 7681
ttyd -p 7681 -W bash &

# 2. Start Cloudflare Tunnel (HTTP2 Mode)
cloudflared tunnel --protocol http2 --url http://localhost:7681
```

*Copy the `https://....trycloudflare.com` URL generated by the second command.*

### 4. Configure the Bot
Edit `tele_shell.py`:
```python
TOKEN = "YOUR_BOT_TOKEN"
AUTHORIZED_USER_ID = 123456789
WEB_TERMINAL_URL = "[https://your-generated-url.trycloudflare.com](https://your-generated-url.trycloudflare.com)"
```

## 📱 Usage Guide

| Mode | Trigger | Description |
| :--- | :--- | :--- |
| **Chat Shell** | Type `ls`, `whoami` | Simple text output. Best for quick checks. |
| **Web Terminal** | Type `cmatrix`, `top` | Opens a popup window with a real Linux terminal. |
| **GUI Launcher** | Type `firefox` | Opens the app on your **computer's** screen. |
| **File Transfer** | `/pull filename` | Downloads files to your phone. |

---

## ⚠️ Security Notes
* **URL Privacy:** Your Cloudflare URL grants full terminal access. **Do not share it.**
* **Auth ID:** The bot is hardcoded to respond ONLY to your `AUTHORIZED_USER_ID`.
